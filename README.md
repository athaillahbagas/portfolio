# Portfolio — Atha

A selective public-facing portfolio of problem-solving and project work.

- **Owner:** [@athaillahbagas](https://github.com/athaillahbagas)
- **Format:** Responsive static site in [`docs/`](docs/), ready for GitHub Pages.
- **Status:** Homepage and one public case study: [Kalku Finance](docs/projects/kalku-finance.html), a financial scenario prototype. The case study distinguishes implementation features from unmeasured user and business outcomes.

## Structure

- `docs/index.html`: Homepage and work index.
- `docs/assets/style.css`: Styling; no build tools or dependencies required.
- `docs/projects/kalku-finance.html`: Public case study covering scope, assumptions, trade-offs, functionality, limitations, and next steps.
- `docs/assets/kalkufinance-preview.jpg`: Screenshot of the public calculator prototype.
- Other pages in `docs/projects/`: Neutral holding pages, not linked from the work index.
- `templates/CASE-STUDY.md`: Standard format for new case studies.
- `EDITORIAL-GUIDELINES.md`: Publishability rules.
- `PUBLISHING.md`: Instructions for deployment and ongoing maintenance.

## Purpose

Public work should answer: What was the problem? What did I personally do? How did I reason about trade-offs? What evidence exists? What would I do differently?

This repository is **not** a mirror of the private work archive. Never upload confidential materials here.
