# Portfolio Editorial Guidelines

1. **Show judgment over volume.** Publish curated work; keep minor assignments in the private archive.
2. **Attribute precisely.** Separate team results from your individual contribution.
3. **Quantify responsibly.** Use verified numbers, source context and definition of each metric; otherwise mark 'not measured'.
4. **No sensitive details.** Remove proprietary data, unreleased case prompts, customer information and company internal plans.
5. **No fictional achievements.** Keep unverified case studies in the private archive; publish only reviewed content and evidenced claims.
6. **Publish a narrative.** Problem → constraints → analysis → alternatives → decision → outcome → reflection.
7. **Review each page before enabling GitHub Pages.** Pages publishes files in its configured folder to the open web.
